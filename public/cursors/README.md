# Face Pack Cursors

Place your custom PNG faces in this folder. The `CustomCursor` component will automatically swap between them based on user interaction.

Required filenames:
1. `default.png` - Used for normal mouse movement.
2. `hover.png` - Used when hovering over links, buttons, or clickable cards.
3. `click.png` - Used on active mousedown events.
4. `text.png` - Used when hovering over text paragraphs or headings.
5. `precision.png` - Used for specific interactive elements or inputs (like the TaxBro browser).
6. `loading.png` - Used during page loads.
7. `not-allowed.png` - Unimpressed face.
8. `help.png` - Curious face.
9. `status.png` - Friendly smiling face.

Ensure the images are approximately 40x40px for the best experience.
